# Project Scope and Ethical Boundaries

## In scope

- Privacy-awareness questionnaire
- Defensive risk scoring
- Security configuration awareness
- Explainable analytics
- Synthetic demo profiles
- Privacy recommendations
- Aggregate synthetic demonstrations
- Student cybersecurity documentation

## Explicitly out of scope

- Scraping social-media platforms
- Searching for real people's accounts
- Account enumeration
- Credential attacks
- Password guessing
- Privacy-setting bypass
- Private-account access
- Tracking individuals
- Identifying anonymous users
- Collecting private messages
- Collecting passwords or authentication secrets
- Building dossiers on real people

## Threat model

The framework treats publicly or broadly exposed personal context as a potential source of:

- phishing personalization
- social engineering
- impersonation
- unwanted contact
- location/routine exposure
- account takeover enablement
- privacy loss

It does **not** claim that any of these outcomes will occur.

## Ethical principle

The system should answer:

> "What privacy/security weaknesses might I have based on the information I voluntarily provide?"

It should never answer:

> "What can I discover about a real person from their social-media accounts?"
